# Type Club Desktop 🚀

**Type Club** — это современный, быстрый и минималистичный настольный Markdown-редактор на базе Electron и ProseMirror, созданный для комфортной и продуктивной работы с текстом, кодом, формулами и таблицами.

## ✨ Ключевые особенности

### 📝 Режимы редактирования

- **Seamless (WYSIWYG)** — «бесшовный» режим: синтаксис Markdown скрывается сразу после ввода, оставляя чистый форматированный текст.
- **Raw Mode** — прямой доступ к исходному коду Markdown для детального контроля.
- **Preview** — режим чтения с финальным рендерингом документа.

### 🔬 Работа с контентом

- **Математика (LaTeX)** — поддержка формул через KaTeX с интерактивным редактированием (инлайн и блочные формулы).
- **Интерактивные таблицы** — визуальный оверлей редактирования: перетаскивание (drag-and-drop) строк и столбцов, добавление и удаление по клику на разделители, rich-text копирование и вставка.
- **Task Lists** — интерактивные списки задач с чекбоксами.
- **Folding** — сворачивание секций по заголовкам для работы с длинными документами.
- **Syntax Highlighting** — подсветка синтаксиса в блоках кода через highlight.js.
- **Интерактивное оглавление (ToC)** — адаптивная навигация по заголовкам с плавным скроллом к разделам.

### ✍️ Инструменты для авторов

- **Focus Mode** — акцентирование внимания на текущем абзаце, предложении или трех строках вокруг курсора.
- **Typewriter Mode** — режим «печатной машинки», удерживающий строку ввода по центру экрана.
- **Stats Toast** — расширенная статистика: подсчет слов, символов, времени чтения и установка целевых лимитов.
- **Спеллчекер** — встроенная проверка орфографии (словари Hunspell ru-RU / en-US), контекстные подсказки исправлений и управление пользовательским словарем в настройках.

### 🖥️ Интерфейс и система

- **Файловый менеджер** — боковая панель с деревом файлов, созданием папок, рабочих пространств и копированием файлов в буфер обмена системы.
- **Вкладки** — работа с несколькими документами, увеличенные области закрытия и закрытие кликом средней кнопки мыши (колесиком).
- **Кастомные диалоги** — стилизованные окна подтверждения удаления файлов и несохраненного выхода в едином дизайне.
- **Система тем** — раздельный выбор дневной и ночной темы (с кнопками-иконками ☀️/🌙), встроенные пресеты (Dark, Light, Peachy, Dissonance), авто-переключение по системной теме и импорт кастомных тем.
- **Настройки** — полноценное модальное окно настроек с категориями (Тема, Язык и словари, Горячие клавиши).
- **Экспорт** — сохранение документов в форматы HTML и PDF.
- **Автосохранение** — надежное фоновое сохранение с настраиваемой задержкой.

## 🛠 Технологический стек

- **Electron 30** — десктопная среда с изолированным контекстом (`contextBridge`).
- **React 18 + Vite** — быстрый и отзывчивый UI с HMR.
- **ProseMirror** — мощное и расширяемое ядро редактора (`@type-club/editor`).
- **Tailwind CSS v4** — современная адаптивная стилизация.
- **TypeScript** — строгая типизация всех компонентов и IPC-мостов.

## 📥 Установка и запуск

1. Клонируйте монорепозиторий:
   ```bash
   git clone https://github.com/chebukeks/type-club-monorepo.git
   cd type-club-monorepo
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:
   ```bash
   npm run dev:desktop
   ```
   *Для подключения к локальному бэкенду:* `npm run dev:desktop:local`

4. Сборка установщика (Windows NSIS / Linux AppImage):
   ```bash
   npm run build:desktop
   ```
