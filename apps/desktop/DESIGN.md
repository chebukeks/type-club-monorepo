# TypeClub Desktop — Дизайн-система и Руководство по интерфейсу (DESIGN.md)

Документ описывает визуальную эстетику, архитектуру дизайн-токенов, компоновку, компоненты, типографику и систему тем десктопного приложения **TypeClub Desktop** (Electron + React + Tailwind + ProseMirror).

---

## 1. Философия и принципы дизайна

1. **Content-First & Distraction-Free (Фокус на тексте)**
   Интерфейс не должен конкурировать с создаваемым контентом. Панели, меню и вспомогательные элементы остаются лаконичными и не привлекают к себе лишнего внимания.
2. **Мягкая глубина и скругления (Soft Depth & Modern Elevation)**
   Вместо резких линий используются скругления (border-radius: `8px`–`16px`), деликатные тени (`shadow-xs` / `shadow-2xl`) и полупрозрачные акриловые слои (`backdrop-blur-xl`).
3. **Бесшовность и отсутствие визуального шума**
   Разделители и сплиттеры (например, граница изменения ширины сайдбара) не имеют статических контрастных рамок и проявляются акцентной подсветкой только при наведении мыши.
4. **100% Theme Isolation (Полная изолированность тем)**
   Все визуальные параметры (цвета, шрифты, границы, подсветка) строго завязаны на семантические CSS-переменные. Никаких захардкоженных hex/rgb цветов в компонентах.
5. **Fluid Micro-interactions (Плавные микро-анимации)**
   Мгновенный тактильный отклик на действия пользователя (100–250ms transitions, easing curves `cubic-bezier(0.4, 0, 0.2, 1)`, поповеры `fadeInPop`).

## 3. Типографика (Typography)

Приложение поддерживает независимую настройку шрифтов для интерфейса, текста статей и блоков кода.

- **UI Font Stack (`--font-ui`):** `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
  - Плотный, разборчивый гротеск с оптимизированным хинтингом для десктопа.
- **Editor Font Stack (`--font-editor`):** Настраивается пользователем (по умолчанию Inter).
  - Базовый кегль: `15px` (регулируется `12px`–`32px`).
  - Межстрочный интервал: `1.6` (регулируется `1.2`–`2.4`).
- **Code Font Stack (`--font-code`):** `'Fira Code', 'Consolas', 'Monaco', 'Courier New', monospace`
  - Используется для блоков кода, инлайн-кода и редактора LaTeX.

## 4. Архитектура окон и компоновка (Layout Structure)

```
+-----------------------------------------------------------------------------------+
| TitleBar (Кастомная шапка: Иконка, Title, MenuBar, Sync Status, Settings, WinControls)|
+-----------------------------------------------------------------------------------+
|  Sidebar (Ширина 180-480px)      |  Editor Viewport (Рабочее пространство)        |
|  - Поиск файлов / фильтр         |  +-------------------------------------------+ |
|  - Дерево каталогов / документов |  | Editor Container (rounded-xl, shadow-xs)  | |
|  - Контекстные действия          |  | - Заголовок документа (H1)                | |
|  - Кнопка создания заметки       |  | - ProseMirror WYSIWYG Content Area        | |
|                                  |  | - LaTeX / Tables / CodeBlocks / Quotes    | |
| [Hover-only invisible resizer]   |  +-------------------------------------------+ |
|                                  |  Floating Stats Toast (Слова, символы, чтение)|
+-----------------------------------------------------------------------------------+
```

### 4.1. TitleBar (Шапка окна)
- Бесшовная интеграция с Electron (`-webkit-app-region: drag` для перемещения окна, `no-drag` для кнопок и меню).
- Высота: `38px`.
- Меню (Файл, Правка, Вид, Справка): открываются вниз с эффектом размытия фона (`backdrop-blur-xl`) и выравниванием по кнопке.

### 4.2. Sidebar (Боковая панель)
- Динамический ресайз с плавным ограничением (`180px` min, `480px` max).
- Разделитель скрыт в покое и плавно подсвечивается акцентным цветом `--accent` только при наведении курсора (`hover:w-[2px]`).

### 4.3. Редактор документов (Editor Container)
- Оформлен в виде центрированного скругленного окна (`rounded-xl border border-[var(--border-default)] shadow-xs bg-[var(--bg-base)]`).
- Максимальная ширина текста: `860px` для максимального комфорта чтения и концентрации.

## 5. Модальные окна и Поповеры

### 5.1. Модалка настроек (Settings Modal)
- Размеры: `940px × 700px` (просторная компоновка с внутренним скроллом).
- Левая навигация: вертикальный список вкладок (1. Язык и словари, 2. Темы оформления, 3. Горячие клавиши).
- Правый контентный фрейм: скругленная карточка (`rounded-xl border border-[var(--border-default)] bg-[var(--bg-base)]`), консистентная с окном редактора.
- Отсутствие лишних разделительных полос: отступы и визуальные карточки формируют естественную группировку.
- Динамический Backdrop & Live Preview: при переключении на вкладку «Темы оформления» размытие заднего плана (`backdrop-filter: blur(0px)`), затемнение фона (`background: transparent`) и тень окна (`box-shadow: none`) плавно отключаются (`transition 0.3s ease`), чтобы пользователь мог максимально реалистично наблюдать за Live Preview темы на основном окне редактора; при возврате на другие вкладки затемнение, тень и размытие плавно восстанавливаются.

### 5.2. Редактор тем (Theme Editor)
- Live Preview: изменение любого колорпикера или шрифта мгновенно отражается во всём приложении без перезагрузки.
- Табы категорий: «Интерфейс», «Редактор», «Код», «Таблицы», «Типографика».
- Защита базовых тем: встроенные темы защищены от случайной перезаписи и при сохранении автоматически дублируются в пользовательские.
- Импорт / Экспорт: обмен темами в чистом формате `.json`.

## 6. Компоненты UI и элементы управления

### 6.1. Переключатели (ToggleSwitch)
- Компактный эргономичный размер: `38px × 20px`.
- В выключенном состоянии: фон `var(--bg-input)`, рамка `var(--border-strong)`, кружок `var(--text-dim)`.
- Во включенном состоянии: фон `var(--accent)`, рамка `transparent`, кружок `#ffffff` с плавной кинематикой `cubic-bezier(0.4, 0, 0.2, 1)`.

### 6.2. Поля ввода (Inputs & Search)
- Фон `var(--bg-input)`, рамка `var(--border-default)`, текст `var(--text-primary)`, плейсхолдер `var(--text-dim)`.
- Фокус: мягкое свечение `ring-2 ring-[var(--accent)]/30` и граница `var(--accent)`.

### 6.3. Цитаты (Blockquotes)
- Левая граница `4px solid var(--editor-blockquote-border)`.
- Скругление углов: `border-radius: 4px` (мягкие закруглённые концы планки без острых углов).
- Фон плашки: `var(--editor-blockquote-bg)` с внутренними отступами `8px 16px`.

### 6.4. Режим предложений (Suggestion Mode)
- Вставки: мягкий бирюзовый/синий фон `rgba(59, 130, 246, 0.15)` с нижней границей.
- Удаления: полупрозрачный зачёркнутый текст `rgba(239, 68, 68, 0.15)`.
- Поповеры действий: карточка `var(--bg-elevated)` со скруглением `10px`, кнопка «Принять» на базе `var(--accent)` и «Отклонить» на базе `var(--bg-hover)`.

## 7. Чеклист для новых компонентов и доработок

При добавлении новых экранов, модалок или элементов интерфейса убедитесь:
1. [ ] Использованы только семантические токены (`var(--...)`), без жестких hex/rgb цветов.
2. [ ] Все интерактивные элементы имеют состояния `:hover`, `:active`, `:focus-visible`.
3. [ ] Текстовые строки вынесены в файлы локализации `ru.ts` и `en.ts`.
4. [ ] Скругления соответствуют общей сетке (`rounded-lg` / `rounded-xl`).
5. [ ] Нет лишних контрастных линий-перегородок — иерархия строится на отступах и поверхностях (`--bg-surface`, `--bg-elevated`).
