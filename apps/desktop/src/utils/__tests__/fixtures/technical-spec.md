# Архитектурная спецификация модуля синхронизации

Данный документ описывает протокол обмена данными и структуру взаимодействия компонентов в распределенной среде.

## Общие требования

Клиентское приложение взаимодействует с сервисом по протоколу WebSocket. Все сообщения передаются в формате JSON.

- Поддержка алгоритма CRDT на базе библиотеки Yjs
- Автоматическое восстановление соединения при обрыве сети
- Локальное сохранение несохраненных правок в кэш IndexedDB

## Матрица совместимости версий

Ниже приведена таблица совместимости клиентских и серверных модулей:

| Компонент | Версия клиента | Версия сервера | Статус поддержки |
| --- | --- | --- | --- |
| Редактор WYSIWYG | 2.1.0 | 1.8.0 | Активна |
| Модуль синхронизации | 1.4.2 | 1.4.0 | Совместим |
| Экспорт в ГОСТ | 3.0.0 | 2.5.0 | Рекомендуется |

## Пример конфигурации

Для инициализации клиента используется метод `createCollabClient`:

```
const client = new CollabClient({
  url: "wss://type-club.ru/ws",
  docId: "doc-12345",
  autoConnect: true,
});
```

> Важно: токен аутентификации должен передаваться в заголовках соединения и обновляться каждые 15 минут.
